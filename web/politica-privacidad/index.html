Política de privacidad

Qué datos se recogen en esta web

Esta web no tiene formularios propios ni guarda datos personales en sus servidores. Los datos solo se facilitan cuando decides usar alguno de estos servicios externos, cada uno con su propia política de privacidad:

  • Substack, para la suscripción a la newsletter (nombre y correo electrónico).
  • Calendly y su pasarela de pago, para reservar y pagar las sesiones de acompañamiento.
  • Skool, para el alta en la comunidad.
  • El correo electrónico, cuando escribes para pedir una charla o una colaboración.

Finalidad y base legal

Los datos se usan para enviarte la newsletter si te suscribes (consentimiento), para gestionar las sesiones que reservas y la comunidad a la que te unes (ejecución de un contrato) y para cumplir las obligaciones fiscales y contables que correspondan (obligación legal).

Conservación

Los datos se conservan mientras se mantenga la relación o no retires tu consentimiento, y después durante los plazos legalmente exigidos.

Tus derechos

Puedes ejercer los derechos de acceso, rectificación, supresión, oposición, limitación y portabilidad escribiendo a [pendiente]. Si consideras que no se han atendido correctamente, puedes reclamar ante la Agencia Española de Protección de Datos (www.aepd.es).

Alojamiento

La web está alojada en Vercel Inc. Al visitarla, el servidor registra datos técnicos (como la dirección IP) durante un tiempo limitado por motivos de seguridad y funcionamiento.
